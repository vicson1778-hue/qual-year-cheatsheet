# Витрина «Магазин здоровья и красоты»

Сайт-каталог (здоровье, красота, дом) с квизом-подбором и формой заявки.
Заявки приходят в Telegram и сохраняются в Google Таблицу.

Адрес после публикации на GitHub Pages:
`https://vicson1778-hue.github.io/qual-year-cheatsheet/shop/`

## Файлы

| Файл | Что внутри |
|---|---|
| `config.js` | Название, ваш Telegram, адрес приёмника заявок, дата каталога |
| `products.js` | Товары и программы с ценами в тенге. Здесь меняете ассортимент |
| `index.html` | Сама витрина |
| `privacy.html` | Политика обработки персональных данных |
| `details.js` | Подробности о товарах: «Чем полезно», преимущества, применение |
| `backend/apps-script.gs` | Код для Google Apps Script: приём заявок с сайта и Telegram-бот |
| `img/tg/` | Фото в JPG для Telegram-бота |

## Настройка (15 минут)

### Шаг 1. Самый быстрый запуск

Откройте `config.js` и впишите свой username в Telegram без `@`:

```js
telegramUsername: "my_username",
```

Уже этого достаточно: после отправки формы у клиента откроется чат с вами,
а текст заявки будет подставлен в сообщение. Клиенту останется нажать «Отправить».

### Шаг 2. Бот для заявок

1. В Telegram откройте `@BotFather`, отправьте `/newbot`, придумайте имя.
   Скопируйте **токен** (строка вида `123456:ABC...`).
2. Напишите своему новому боту любое сообщение (например, «привет»),
   иначе он не сможет писать вам первым.
3. Узнайте свой **chat id**: напишите `@userinfobot`, он пришлёт число `Id`.
   Если хотите получать заявки в группу, добавьте бота в группу,
   а id группы узнайте через того же `@userinfobot` (он начинается с `-100`).

### Шаг 3. Приёмник заявок (Google Таблица)

1. Создайте новую Google Таблицу, назовите, например, «Заявки с сайта».
2. Меню **Расширения → Apps Script**. Удалите всё в редакторе и вставьте код из
   `backend/apps-script.gs`. Сохраните.
3. Слева **Настройки проекта (шестерёнка) → Свойства скрипта → Добавить**:
   - `TELEGRAM_TOKEN` = токен из шага 2
   - `TELEGRAM_CHAT_ID` = ваш id из шага 2
4. Вверху выберите функцию `testTelegram` и нажмите **Выполнить**.
   Разрешите доступ. В Telegram должно прийти «Проверка...».
5. **Начать развёртывание → Новое развёртывание → Тип: Веб-приложение**.
   - Запуск от имени: **я**
   - Доступ: **все**
   Нажмите «Начать развёртывание» и скопируйте **URL веб-приложения**.
6. Вставьте этот URL в `config.js`:

```js
endpoint: "https://script.google.com/macros/s/.../exec",
```

Теперь каждая заявка сразу приходит от бота в Telegram и появляется строкой в таблице
со статусом «новая». Статус можно менять вручную: «связался», «заказ», «отказ».

> Если меняете код в Apps Script, делайте **Управление развёртываниями → Изменить → Новая версия**,
> тогда URL останется прежним.

### Шаг 3а. Telegram-бот

Тот же скрипт из шага 3 работает и как бот. Отдельный сервер не нужен.

**Что умеет бот:**
- меню: программы здоровья, каталог по разделам, подбор за 3 вопроса, скачать каталог, заявка, написать консультанту;
- заявка в чате (имя, номер одной кнопкой, комментарий): строка в листе «Заявки» и уведомление вам;
- напоминания о повторной покупке раз в день в 10:00;
- рассылки всем подписчикам, в том числе с кнопкой «Записаться».

Товары, цены и описания бот берёт с сайта, поэтому менять их нужно только на сайте. Бот обновляет данные раз в час.

**Запуск (после шага 3):**
1. Убедитесь, что веб-приложение развёрнуто (шаг 3.5) и в свойствах скрипта есть `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`.
2. В редакторе Apps Script выберите функцию `setup` и нажмите **Выполнить**. Разрешите доступ.
   Скрипт создаст листы, подключит бота к Telegram, добавит меню команд и ежедневные напоминания.
   В Telegram придёт «✅ Бот подключён».
3. Впишите имя бота в `config.js` (`botUsername: "имя_бота"`), и на сайте появится кнопка «Telegram-бот».
4. Если `setup` пишет, что не нашёл адрес веб-приложения, скопируйте URL …/exec в свойство `WEBAPP_URL` и запустите `setup` снова.

**Листы в Google Таблице:**

| Лист | Что там |
|---|---|
| Заявки | заявки с сайта и из бота, колонка «Источник» показывает откуда |
| Подписчики | все, кто нажал /start. Статус: активен, отписан или заблокировал |
| Покупки | для напоминаний: дата покупки, клиент (@username), товар, через сколько дней напомнить |
| Записи | кто нажал «Записаться» в рассылке |
| Рассылки | история рассылок |

**Ваши команды в боте** (работают только с вашего аккаунта из `TELEGRAM_CHAT_ID`):
- `/admin`: список команд;
- `/broadcast текст`: рассылка. Сначала бот покажет предпросмотр и спросит, добавлять ли кнопку «Записаться»;
- `/buy @username Товар; 30`: добавить покупку, бот напомнит клиенту через 30 дней (по умолчанию 28);
- `/remind`: проверить напоминания прямо сейчас;
- `/stats`: подписчики, заявки, ожидающие напоминания.

**Важно про напоминания и рассылки:** Telegram разрешает боту писать только тем, кто сам нажал /start.
Поэтому просите клиентов подписаться на бота, например отправляйте им ссылку `https://t.me/имя_бота`.
Ссылки сразу на товар или программу: `https://t.me/имя_бота?start=item_omega`, `https://t.me/имя_бота?start=prog_c-gut`.

> После любого изменения кода делайте **Управление развёртываниями → Изменить → Новая версия**.
> Адрес останется прежним, `setup` запускать заново не нужно.

### Шаг 4. Цены и товары

В `products.js` у каждого товара поле `priceKzt`: розничная цена из каталога Казахстана в тенге.
На сайте она показывается в рублях: `priceKzt × kztToRub` (сейчас 0,2), с округлением до 10 ₽
и звёздочкой «примерная цена, уточняйте у консультанта».

- Новый каталог: обновите `priceKzt` у товаров и `catalogDate` в `config.js`.
- Изменился курс: поменяйте только `kztToRub` в `config.js`, все цены пересчитаются сами.
- Программы считают цену сами как сумму входящих товаров.

Добавить товар: скопируйте любую строку `{ id: ..., }`, поменяйте `id` (латиницей, уникальный),
название, цену, категорию (`health`, `beauty`, `home`) и теги для квиза.

## Как отправлять ссылку

Добавляйте метку источника, чтобы в таблице было видно, откуда пришёл человек:

- `.../shop/?from=instagram`
- `.../shop/?from=whatsapp`
- `.../shop/?from=olga` (ссылка для партнёра Ольги)
- `.../shop/#quiz` (сразу на подбор)
- `.../shop/#programs` (сразу на программы)

## Важно

- В описаниях БАД не пишите, что продукт «лечит». Только «поддерживает», «источник».
- Проверьте правила компании для личных сайтов дистрибьюторов (использование товарных знаков, фото, цены).
- Сайт не принимает оплату: заказ оформляется после консультации.

## Каталог для скачивания (PDF)

- `katalog-2026.pdf`: полный официальный каталог (252 стр., цены в тенге). Главная кнопка внизу сайта. При выходе нового каталога замените этот файл, имя оставьте прежним.

- `catalog.html`: страница-каталог (все программы, наборы и товары с описаниями из `details.js`).
- `catalog.pdf`: готовый файл для скачивания, кнопка внизу главной страницы.
- После изменения цен, товаров или описаний пересоберите PDF (нужны Node.js и Playwright):

```
npx playwright install chromium   # один раз
node shop/tools/make-catalog-pdf.js
```

Или попросите Claude пересобрать каталог.
